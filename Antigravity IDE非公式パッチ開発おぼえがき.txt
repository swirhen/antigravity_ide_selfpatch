================================================================================
Antigravity IDE 統合パッチ おぼえがき (モジュール分離・配布パッケージ版)
【セッション一覧 (現在セッション最上位・ピン留め・キーボード選択) + :rename + 改行パッチ】
================================================================================

【目的】
Antigravity IDE の組み込みチャット（Agent Side Panel）において、
以下のUI改善機能をモジュール分離アーキテクチャで実装する：

1. 【セッション一覧機能 (Session Drawer & Pin & :resume キーボード選択)】
   チャットペイン最上部に折りたたみ式セッション一覧バーを設置。
   - 初期起動時・新規会話時: 「過去セッション (件数)」と表示。
   - 会話選択時: バー上に現在の「セッション名」および「ピン留め状態（📌 ピン留め中）」を常時表示。
   - バー上のピンボタンから、現在のセッションを直感的にワンクリックでピン留め / 解除可能。
   - コロンコマンド `:resume` (短縮 `:res`) またはショートカット `F4` でドロワーを開閉。
   - ドロワー一覧では、現在開いているセッションがピン留め・更新時刻を問わず【常に最上位（一番上）】に固定配置。
   - 現在開いているセッションの左端には【青い二重丸（ラジオアイコン）】を表示（ピン留め時は金色のピンも並列表示）。
   - ドロワーを開いた際、自動的に最上位（現在セッション）にキーボード選択が当たり、可視範囲へ自動スクロール。
   - ドロワーオープン直後のマウスオーバーによる意図しない選択奪取を防止（3px移動検知による保護ガード）。
   - キーボードの `↑` / `↓` キーでセッションを選択、`Enter` で決定、`Escape` でキャンセル。
   - 各セッション右側のピンボタン（または `:pin` / `:p`, `:unpin` / `:up`）でピン留め可能。
   - ピン留めされたセッションは金色アイコンで上位に固定表示される。
   - 各セッション右側のゴミ箱アイコンでセッション削除が可能。
   - 右側には「＋ 新規」ボタンを常設し、いつでも新しい会話を開始可能。
   - コロンコマンド `:new` (短縮 `:n`) で、いつでも即座に新規セッションを開始可能。

2. 【:rename コマンド (Session Rename)】
   チャット欄に `:rename <新しいセッション名>` (短縮 `:ren <名前>`) と入力して Enter で、
   AIへのリクエストを発生させずに、クライアント側からGoogle同期バックエンド（Unified State Sync）
   および画面のReduxステートを直接更新し、セッション名を瞬時に永続変更。
   引数なし（`:rename` または `:ren` 単体）で Enter を押した場合は、現在のセッション名を
   あらかじめ代入・全選択した入力ダイアログが出現。
   ※ダイアログ終了時（決定・キャンセル・Escape問わず）、自動的にチャット入力欄へフォーカス復帰。

3. 【チャット改行パッチ (Keybinding Patch)】
   チャット入力欄の挙動を「Enterで改行 / Ctrl+Enter (MacはCmd+Enter) で送信」に変更。
   ただし `:` で始まる上記コマンドは、Ctrl を押さずに通常の `Enter` 1回で即座に実行される。

4. 【セッション操作ショートカットキー (Keybindings)】
   チャットペインにフォーカスがある時（when: `antigravity.agentSidePanel.isFocused`）限定で
   以下のキーボードショートカットを即座に利用可能：
   - セッション一覧（ドロワー）: `F4`（開いている時にもう一度押すと閉じてチャット欄にフォーカス復帰）
   - セッション名変更: `F2`（完了・キャンセル後にチャット欄にフォーカス復帰）
   - ピン留め: `F6`
   - ピン留め解除: `Ctrl + F6`
   - 新規セッション: `Ctrl + F4`
   ※VS Codeの内部コマンド（`antigravity.session.*`）として登録されているため、
     `keybindings.json` からユーザーがいつでも自由にお好みのキーへ変更可能。

--------------------------------------------------------------------------------
1. アーキテクチャ（モジュール分離）
--------------------------------------------------------------------------------
本パッチは、メンテナンス性とアップデート耐性を最大化するため、2つの要素に分離されています：

1. 【独立モジュール】: `antigravity-session-patch.js`
   ドロワーUI、ソートロジック、名前変更ダイアログ、ピン留め処理、キーボード移動などの
   全ロジックが綺麗にインデントされた独立したJavaScriptファイル（開発・保守用原本）。

2. 【自動インストーラー】: `apply_patch.py`
   手元の `antigravity-session-patch.js` を読み込み、本体ファイルの先頭に安全にバンドル注入
   するとともに、最小限のフック適用、`product.json` チェックサム更新、
   `keybindings.json` のショートカット登録までを全自動で行うスクリプトです。
   ※Electron Sandbox や CSP の制約により実行時動的ロードが制限されるため、
     インストーラーが安全に先頭展開（バンドル注入）することで 100% 確実に動作させます。

--------------------------------------------------------------------------------
2. 配布ファイル構成
--------------------------------------------------------------------------------
`antigravity_ide_selfpatch/` フォルダ配下に以下のファイル群をまとめて管理・配布します：

  antigravity_ide_selfpatch/
  ├── antigravity-session-patch.js                  # 独立モジュール本体
  ├── apply_patch.py                                # ワンクリック自動インストーラー
  ├── Antigravity IDE非公式パッチおぼえがき.txt       # 本ドキュメント
  └── backups/                                      # ステップ別・初期バックアップ格納先

--------------------------------------------------------------------------------
3. 他環境への適用・アップデート後の再適用手順
--------------------------------------------------------------------------------
他人に勧める場合や、Antigravity IDE のアップデート後にパッチを再適用したい場合は、
ターミナル（PowerShell等）で以下のコマンドを1回実行するだけです：

```powershell
python "c:\Users\swirh\Downloads\projects\antigravity_ide_selfpatch\apply_patch.py"
```

スクリプト実行後、IDE で `Ctrl + Shift + P` -> `Developer: Reload Window` を実行するか、
IDE を再起動すれば即座に全機能が反映されます。

--------------------------------------------------------------------------------
4. 元に戻す方法（ロールバック）
--------------------------------------------------------------------------------
パッチを完全に解除して初期状態に戻す場合は、自動作成されたバックアップから復元します：

[Windows PowerShell]
```powershell
Copy-Item "$env:LOCALAPPDATA\Programs\Antigravity IDE\resources\app\out\vs\workbench\workbench.desktop.main.js.backup_before_patch" "$env:LOCALAPPDATA\Programs\Antigravity IDE\resources\app\out\vs\workbench\workbench.desktop.main.js" -Force
Remove-Item "$env:LOCALAPPDATA\Programs\Antigravity IDE\resources\app\out\vs\workbench\antigravity-session-patch.js" -ErrorAction SilentlyContinue
```
復元後、同様に `Developer: Reload Window` を実行してください。
