# Antigravity IDE 自己修正パッチ

Antigravity IDE の Agent Side Panel に対して、セッション管理や入力補助、AI 残量表示を追加するための非公式パッチです。

このリポジトリは、実装そのものを保守しやすいように、

- 独立したパッチ本体: `antigravity-session-patch.js`
- 自動適用スクリプト: `apply_patch.py`
- 復元用スクリプト: `rollback.py`

の 3 層で構成されています。

---

## 目的

本パッチは「理想の UI を作る」ことよりも、Antigravity IDE の実際の内部状態と構造に合わせて、
実運用で使える改善を追加することを重視します。

主な追加機能:

- セッション一覧ドロワー
- セッション名変更
- ピン留め / ピン解除
- 新規セッション開始
- セッションのアーカイブ / アーカイブ解除
- Enter 改行 / Ctrl+Enter 送信
- コロンコマンドの即時実行
- AI クォータ残量表示（Vitals）

---

## 実装上の前提

本パッチは Antigravity IDE の内部 JavaScript を直接触るため、以下の前提を前提に動作します。

- `workbench.desktop.main.js` に対して直接差し込みを行う
- IDE の内部状態と DOM 構造に依存する
- セッション一覧やタイトル更新は内部 state に強く依存する
- Vitals はローカルの API / 状態情報に依存する
- `product.json` と `keybindings.json` の整合性を保つ必要がある

そのため、IDE のアップデートで本体側の構造が変わると、適用位置や記述の調整が必要になります。

---

## 主要機能

### 1. セッション一覧ドロワー

- `F4` または `:resume` / `:res` で開閉
- 現在開いているセッションを優先表示
- 優先順位は、実装上は「現在セッション > ピン留め > 更新時刻」
- キーボード操作: `↑` / `↓` / `Enter` / `Escape`
- ドロワー内の検索入力に対応
- 各セッションの右側にピン留め・アーカイブ・削除操作を配置
- ドロワー最下部に「アーカイブ済み」セクションを折りたたみ表示（開閉状態を保持）

### 2. セッション名変更

- `F2` または `:rename <名前>` / `:ren <名前>`
- 引数なしで実行すると、現在のタイトルがあらかじめ入ったダイアログを表示
- チャットUIのタイトルクリックでも起動可能
- 変更時はチャット入力欄へフォーカスを戻す

### 3. ピン留め

- `F6` でピン留め
- `Ctrl + F6` でピン解除
- `:pin` / `:p`, `:unpin` / `:up` でも操作可能

### 4. 新規セッション

- `Ctrl + F4`
- `:new` / `:n`

### 5. セッションのアーカイブ / アーカイブ解除

- 各セッションのアイコンボタンからアーカイブ・解除が可能
- `:archive` / `:arc` で現在のセッションをアーカイブ
- `:unarchive` / `:unarc` で現在のセッションのアーカイブを解除
- 設定画面からコマンド文字列のカスタマイズに対応

### 6. Enter 改行 / Ctrl+Enter 送信

- 既定は「Enter 改行 / Ctrl+Enter 送信」
- コロンコマンドは Enter 1 回で即時実行
- 設定画面で ON / OFF を切り替え可能

### 7. AI クォータ残量表示（Vitals）

- AI クォータ残量とサービス状況を入力欄周辺に表示
- 5h / 7d の残量を表示
- 10% 未満は赤、25% 以下は黄、通常時は緑
- ホバー時に詳細情報を表示

## インストール

### 必要条件

- Python 3.8 以上
- Antigravity IDE がインストール済み

### 実行手順

```powershell
python "C:\path\to\antigravity_ide_selfpatch\apply_patch.py"
```

実行後、Antigravity IDE で `Developer: Reload Window` を実行すると反映されます。

---

## アップデート後の再適用

IDE を更新した場合、内部本体ファイルが置き換わることがあります。
その場合は、再度次のコマンドで再適用します。

```powershell
python "C:\path\to\antigravity_ide_selfpatch\apply_patch.py"
```

その後、再読み込みまたは再起動を行います。

---

## バックアップとロールバック

本パッチは本体の JS を直接書き換えるため、常にバックアップを前提に扱います。

必須バックアップ対象:

- `workbench.desktop.main.js`
- `product.json`
- `keybindings.json`
- `antigravity-session-patch.js`

開発時は、各作業ステップごとにバックアップを作成し、変更に失敗した場合は元の状態へ戻す運用を守ります。

ロールバックは、バックアップ済みの本体ファイルを復元するか、`rollback.py` を利用して元に戻します。

---

## 使い方の目安

通常の利用では、以下の流れで使います。

1. `apply_patch.py` を実行してパッチを適用
2. IDE を再読み込み
3. `F4` / `:resume` でセッション一覧を開く
4. 必要に応じて `F2` / `F6` / `Ctrl + F4` を利用
5. `:rename`, `:pin`, `:archive`, `:new` などのコロンコマンドを利用

---

## 注意事項

- このプロジェクトは非公式パッチです。
- IDE 本体のアップデートや内部変更により、パッチの適用位置がずれることがあります。
- 仕様の変更や環境差異がある場合、実装依存の箇所は調整が必要です。
- バックアップを残さずに本体を改変しないことが最重要です。

---

## まとめ

このパッチは、単純な機能追加ではなく、Antigravity IDE の内部状態に対して安全に改善を加えるための運用設計を前提にしています。

実際のポイントは次の 3 つです。

- 変更対象が本体の内部 JS であること
- 実装依存を明示していること
- バックアップとロールバックを必須にしていること

これにより、更新時の破損や再適用のしにくさを減らし、修正を継続しやすくしています。
